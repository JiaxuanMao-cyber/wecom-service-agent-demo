# mjx 公开静态演示

入口为 `index.html#service`，保留客户服务、问题协同、主动服务、策略管理和评估审核。
所有账户、交易、人工处理、发送及审核交互均为 Mock；不调用模型或公司接口，不向客户发送消息。
历史业务情景仅用于展示，不能作为当前产品条款、个人账户查询结果或投资建议。

公开版不包含原始聊天、本地案例索引、公司合同、数据库、环境配置或密钥。
顾问身份、来源身份和指纹已经替换为演示标识；任何来源匹配仅表示演示资产内部对应，不证明真实来源核验或正式审核。
草稿及操作状态仅保存在当前浏览器，不在不同用户或设备之间共享。

本地运行：在仓库根目录执行 `python -m http.server 8766 --bind 127.0.0.1`，访问 `/mjx/`。
